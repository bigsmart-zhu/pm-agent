# 视频通话功能文档

## 一、功能概述

### 1.1 功能定位
视频通话是陪伴机器人核心连接功能之一，让老人与家人随时进行面对面的视频沟通，缩短距离感，增强情感联系。

### 1.2 目标用户
- **主要用户**：使用陪伴机器人的老人（65岁+）
- **关联用户**：子女/家庭成员（通过手机APP/微信小程序使用）

### 1.3 核心价值
- **零门槛使用**：一键呼叫，无需复杂操作
- **被动接听**：老人无需主动操作，来电自动接听
- **安全可控**：白名单机制，避免骚扰电话
- **大屏体验**：机器人10寸大屏，看得更清楚

## 三、功能模块详情

### 3.1 发起通话（子女端）

#### 3.1.1 功能描述
子女通过手机APP或微信小程序，向机器人端发起视频通话请求。

#### 3.1.2 功能规格

| 项目 | 规格 |
|------|------|
| 发起方式 | APP/微信小程序 |
| 联系人选择 | 家庭成员列表（头像+昵称） |
| 呼叫时长 | 最长60秒无人接听自动挂断 |
| 呼叫提示 | 机器人端响铃+屏幕显示来电者信息 |
| 取消呼叫 | 发起方可随时取消 |

#### 3.1.3 呼叫流程
```
1. 子女打开APP/小程序
2. 选择要呼叫的家庭成员（机器人）
3. 点击「视频通话」按钮
4. 机器人端收到呼叫请求
5. 显示来电者头像+昵称+关系
6. 播放来电铃声
7. 等待接听（最长60秒）
8. 接听成功 → 进入通话界面
9. 超时未接 → 显示未接来电
```

### 3.2 接听机制（机器人端）

#### 3.2.1 功能描述
机器人端接收呼叫请求，支持自动接听和手动接听两种模式。

#### 3.2.2 接听模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **自动接听** | 来电后3秒自动接听（默认） | 老人不会操作、行动不便 |
| **手动接听** | 需点击屏幕接听按钮 | 有一定操作能力的老人 |
| **静音拒接** | 设置时段自动拒接（如睡眠时间） | 避免打扰休息 |

### 3.4 通话记录

#### 3.4.1 功能描述
记录所有通话历史，包括已接、未接、拒接来电，支持一键回拨。

#### 3.4.2 记录类型

| 类型 | 图标 | 说明 |
|------|------|------|
| 已接来电 | ✅ | 通话已完成 |
| 未接来电 | ❌ | 未接听（超时/拒接） |
| 已拒接 | 🚫 | 主动拒接 |

#### 3.4.3 记录内容

```
通话记录列表
├── 2026-05-07 15:30  ✅ 女儿 · 小红  通话 5分23秒
├── 2026-05-07 10:15  ❌ 儿子 · 小明  未接来电
├── 2026-05-06 20:00  ✅ 女儿 · 小红  通话 12分08秒
└── 2026-05-06 14:30  🚫 未知号码     已拒接（不在白名单）
```

#### 3.4.4 未接来电提醒
- **显示位置**：首页顶部通知栏
- **提醒方式**：角标 + 语音播报
- **提醒内容**：「您有1个未接来电，来自女儿小红」
- **操作**：点击查看详情，支持一键回拨

## 四、技术规格

### 4.1 视频通话技术方案

| 项目 | 规格 |
|------|------|
| 协议 | WebRTC |
| 分辨率 | 720p（自适应带宽） |
| 帧率 | 15-30fps（自适应） |
| 音频编码 | Opus |
| 视频编码 | H.264 / VP8 |
| 网络要求 | 上行 ≥ 512Kbps，下行 ≥ 1Mbps |
| 延迟 | < 500ms |

### 4.2 性能要求

| 指标 | 要求 |
|------|------|
| 呼叫响应时间 | < 3秒 |
| 视频连接建立 | < 5秒 |
| 弱网抗性 | 丢包率30%仍可通话 |
| 通话稳定性 | 30分钟通话不掉线 |

### 4.3 安全要求

- 端到端加密通话
- 白名单验证机制
- 敏感时段拒接设置
- 通话记录本地加密存储

## 五、交互设计

### 5.1 发起通话流程（子女端）

```
1. 打开APP/小程序
2. 首页显示家庭成员列表
3. 点击联系人头像
4. 弹出操作菜单：[视频通话] [语音通话] [发消息]
5. 点击「视频通话」
6. 显示呼叫中界面（动画 + 铃声）
7. 等待接听...
   ├── 接听成功 → 进入通话界面
   ├── 超时未接 → 提示"对方未接听，请稍后再试"
   └── 对方拒接 → 提示"对方拒绝了通话"
```

### 5.2 接听通话流程（机器人端）

```
1. 来电响铃
2. 屏幕显示来电者信息
3. （自动接听模式）3秒后自动接听
4. （手动接听模式）点击「接听」按钮
5. 进入通话界面
6. 显示对方画面（全屏）
7. 显示自己画面（小窗）
8. 显示操作按钮
9. 点击「挂断」结束通话
10. 显示通话时长统计
```
