# 微信小程序「陪伴机器人」功能文档

## 一、产品概述

### 1.1 产品定位
微信小程序「陪伴机器人」是机器人的移动端控制平台，连接用户与家庭陪伴机器人，让子女/家庭成员可以随时随地与老人互动、管理设备、传递关怀。

### 1.2 目标用户
- **主要用户**：家庭成员（子女为主）
- **辅助用户**：护工、社区服务人员

### 1.3 核心价值
- **远程关怀**：随时发起视频通话、看望老人
- **便捷分享**：即拍即传照片，传递温暖
- **设备管理**：远程管理机器人设置
- **健康守护**：用药提醒，确保老人按时服药

## 四、通知中心

### 4.1 功能描述
汇聚所有与机器人、老人相关的重要通知，让用户第一时间掌握家庭动态。

### 4.2 通知类型

| 类型 | 图标 | 说明 | 优先级 |
|------|------|------|--------|
| **设备异常** | ⚠️ | 设备离线/电量低/网络异常 | 🔴高 |
| **用药提醒** | 💊 | 用药时间到了/未服药 | 🔴高 |
| **未接来电** | 📞 | 视频通话未接听 | 🟡中 |
| **新照片** | 📷 | 老人/机器人新拍摄的照片 | 🟢低 |
| **家人动态** | 👨‍👩‍👧 | 其他家庭成员的操作动态 | 🟢低 |
| **系统通知** | 🔔 | 版本更新/功能维护 | 🟢低 |

### 4.3 通知详情

#### 4.3.1 设备异常通知
```
【⚠️ 设备离线提醒】
爷爷的机器人已离线超过 30 分钟
原因：可能是网络断开或电源关闭
时间：2026-05-11 16:30
操作：[查看设备] [联系客服]
```

#### 4.3.2 用药提醒通知
```
【💊 用药提醒】
爷爷今天还有 1 次药未服用
药品：降压药（上午 8:00）
提醒时间：08:00 已发送
状态：❌ 未确认
操作：[联系爷爷] [延迟提醒]
```

#### 4.3.3 未接来电通知
```
【📞 未接来电】
爷爷错过了您的视频通话
时间：2026-05-11 15:30
通话时长：0秒
操作：[立即回拨] [发消息]
```

### 4.4 通知设置

| 设置项 | 说明 |
|--------|------|
| 推送开关 | 开启/关闭各类通知推送 |
| 免打扰时段 | 设置不推送的时间段 |
| 推送频率 | 实时/每小时汇总 |
| 声音设置 | 开启/关闭声音 |

## 五、家庭相册

### 5.1 功能描述
家庭共享相册，支持照片上传、浏览、管理，连接家人之间的情感纽带。

### 5.2 功能架构

```
家庭相册
├── 照片上传
│   ├── 即拍即传（拍照后直接上传）
│   ├── 相册选择（从手机相册选择）
│   └── 批量上传（一次最多9张）
├── 相册浏览
│   ├── 全部照片（按时间倒序）
│   ├── 按成员筛选
│   └── 按时间筛选
├── 智能回顾
│   ├── 本周回顾（自动生成）
│   ├── 生日回顾（特殊日期）
│   └── 自定义回顾（选择照片生成）
└── 分享邀请
    ├── 生成邀请码
    └── 分享链接
```

### 5.3 照片上传流程

```
1. 点击「+」上传按钮
2. 选择上传方式：
   ├── 📷 即拍即传 → 调用相机 → 拍照 → 确认上传
   └── 🖼️ 从相册选择 → 选择照片 → 确认上传
3. 设置可见范围（可选）
   ├── 所有家人可见
   └── 指定成员可见
4. 上传成功
   └── 机器人端收到新照片提醒
```

### 5.4 上传规格

| 项目 | 规格 |
|------|------|
| 支持格式 | JPG、PNG、HEIC |
| 单张限制 | 20MB |
| 批量上传 | 一次最多 9 张 |
| 每天上限 | 100 张 |
| 存储位置 | 腾讯云 COS |

### 6.2 功能架构

```
视频通话
├── 发起通话
│   ├── 选择联系人（家庭成员/机器人）
│   ├── 呼叫机器人
│   └── 呼叫状态显示
├── 通话界面
│   ├── 对方画面（机器人端画面）
│   ├── 本地预览（自己的画面）
│   ├── 通话计时
│   └── 操作按钮
├── 通话记录
│   ├── 已接来电
│   ├── 未接来电
│   └── 一键回拨
└── 白名单管理
    ├── 查看白名单
    └── 管理呼叫权限
```

### 6.3 发起通话流程

```
1. 首页点击「视频通话」入口
2. 显示联系人列表
3. 选择要呼叫的机器人/家庭成员
4. 点击「呼叫」按钮
5. 等待对方接听...
   ├── 接听成功 → 进入通话界面
   ├── 超时未接 → 显示「对方未接听」
   └── 对方拒接 → 显示「对方已拒绝」
6. 通话结束 → 返回首页
```

## 九、分享邀请

### 9.1 功能描述
邀请其他家庭成员加入，共同使用陪伴机器人。

### 9.2 邀请流程

```
1. 点击「邀请家人」按钮
2. 选择邀请方式：
   ├── 生成邀请码（发送给他人输入）
   └── 分享小程序链接
3. 设置被邀请人权限：
   ├── 管理员（可管理设备、添加成员）
   ├── 成员（可通话、相册、查看通知）
```
