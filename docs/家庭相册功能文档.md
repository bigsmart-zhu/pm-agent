# 家庭相册功能文档

## 一、功能概述

### 1.1 功能定位
家庭相册是陪伴机器人核心功能之一，连接家庭成员的情感纽带。支持照片上传、管理、浏览和分享，让老人随时查看家人的照片，子女也能通过照片传递关怀。

### 1.2 目标用户
- **主要用户**：使用陪伴机器人的老人（65岁+）
- **关联用户**：子女/家庭成员（通过小程序/APP使用）

### 1.3 核心价值
- **情感连接**：老人随时看到家人照片，减少孤独感
- **便捷分享**：子女即拍即传，操作简单
- **智能回顾**：自动生成视频，重温美好时光

---

## 二、功能架构

```
家庭相册
├── 照片上传
│   ├── 支持微信小程序 即拍即传
│   └── 有人上传新照片 → 家庭成员收到提醒
├── 相册池
│   ├── 家庭成员账号可见
│   └── 支持批量选择成员可见范围
├── 时间线浏览
│   ├── 按「今天/本周/今年」快速定位
│   └── 智能回顾 → 照片生成视频
└── 相册分享邀请
    └── 生成邀请码，子女帮父母建账号
```

## 三、功能模块详情

### 3.1 照片上传

#### 3.1.1 功能描述
家庭成员通过微信小程序将照片上传到家庭相册，支持即拍即传和相册选择两种方式。

#### 3.1.2 功能规格

| 项目 | 规格 |
|------|------|
| 上传方式 | 微信小程序 |
| 支持格式 | JPG、PNG、HEIC |
| 单张限制 | 20MB |
| 批量上传 | 一次最多9张 |
| 即拍即传 | 支持拍照后直接上传 |
| 上传提醒 | 新照片上传后，机器人端弹窗+语音提醒 |

#### 3.1.3 提醒机制
- **触发条件**：有新照片上传至相册池
- **提醒方式**：
  - 机器人屏幕弹窗显示新照片缩略图
  - 语音播报："您有新的家庭照片，快去看看吧"
  - 首页照片区角标显示新照片数量
- **提醒频率**：同一批次只提醒一次

---

### 3.2 相册池

#### 3.2.1 功能描述
家庭照片的存储和展示中心，支持按成员权限管理可见范围。

#### 3.2.2 功能规格

| 项目 | 规格 |
|------|------|
| 可见范围 | 家庭成员账号可见 |
| 权限管理 | 支持批量选择成员可见范围 |
| 照片排序 | 按上传时间倒序（最新在前） |
| 展示方式 | 网格视图 + 时间线视图 |
| 单页数量 | 默认20张，支持加载更多 |

#### 3.2.3 可见范围设置
- **默认状态**：所有家庭成员可见
- **批量设置**：
  - 上传时可选择可见成员
  - 支持「全选」「取消全选」
  - 已上传照片支持修改可见范围
- **成员列表**：显示家庭成员头像和昵称

---

### 3.3 时间线浏览

#### 3.3.1 功能描述
提供多维度的照片浏览方式，支持快速定位和智能回顾。

#### 3.3.2 快速定位

| 时间维度 | 说明 |
|----------|------|
| 今天 | 显示今日上传的所有照片 |
| 本周 | 显示本周（周一至周日）的照片 |
| 今年 | 显示本年度的照片 |
| 全部 | 显示所有照片，按月份分组 |

#### 3.3.3 智能回顾
- **功能描述**：系统自动选取照片生成回顾视频
- **触发时机**：
  - 每周日晚8点自动生成「本周回顾」
  - 每月1日生成「上月精彩」
  - 重要节日（春节、中秋等）生成专题回顾
- **视频规格**：
  - 时长：30-60秒
  - 配乐：温馨轻音乐
  - 转场：淡入淡出效果
  - 字幕：可选显示照片日期

---

### 3.4 相册分享邀请

#### 3.4.1 功能描述
通过邀请码机制，让子女帮助父母快速建立家庭账号，加入相册共享。

#### 3.4.2 功能规格

| 项目 | 规格 |
|------|------|
| 邀请方式 | 生成6位数字邀请码 |
| 有效期 | 24小时 |
| 使用次数 | 单次有效 |
| 通知方式 | 短信/微信推送邀请码 |

#### 3.4.3 邀请流程
```
1. 子女端生成邀请码
2. 系统发送邀请码至父母手机
3. 父母在机器人端输入邀请码
4. 自动创建账号并绑定家庭关系
5. 加入家庭相册，可查看/上传照片
```

## 五、技术规格

### 5.1 存储方案
- **云端存储**：腾讯云COS
- **缩略图**：自动生成200×200px缩略图
- **原图**：保留上传原图
- **存储周期**：永久保存

### 5.2 性能要求
| 指标 | 要求 |
|------|------|
| 缩略图加载 | < 500ms |
| 原图加载 | < 2s |
| 视频生成 | < 5分钟（异步处理）|
| 页面切换 | < 300ms |

### 5.3 安全要求
- 照片传输使用HTTPS加密
- 存储采用私有 bucket，通过临时签名访问
- 敏感操作需二次确认
