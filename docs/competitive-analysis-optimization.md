# PM Agent 竞品分析能力优化方案

> **目标**：基于 AI 智能体创作平台原型分析，提炼竞品分析能力，优化 PM Agent 的 PRD 生成模块

---

## 一、从原型中提炼的竞品分析框架

### 1.1 分析维度

基于 AI 智能体创作平台原型的结构，提炼出以下竞品分析维度：

| 维度 | 分析要点 | 输出格式 |
|------|---------|---------|
| **产品定位** | 一句话定位、核心价值主张 | 定位陈述 |
| **目标用户** | 主要用户、次要用户、非目标用户 | 用户画像卡片 |
| **功能模块** | 核心功能、辅助功能、差异化功能 | 功能清单 + RICE 评分 |
| **交互流程** | 用户主流程、分支流程、异常流程 | 流程图 + 用户故事 |
| **商业模式** | 免费功能、付费功能、变现路径 | 商业画布 |
| **竞争态势** | 直接竞品、间接竞品、潜在竞品 | 竞品矩阵 |

### 1.2 原型提取方法

#### 方法 A：从 Axure 原型提取（axure-online / axure-local）
1. 扫描项目结构
2. 提取页面内容（标题、文本、交互）
3. 分析页面流转关系
4. 识别核心功能模块

#### 方法 B：从产品描述提取（web_fetch）
1. 抓取产品介绍页面
2. 提取功能清单
3. 分析用户价值主张
4. 识别商业模式

## 四、集成到工作流

### 4.1 路由规则更新

```markdown
| 用户说的特征 | 路由到 | Agent的判断逻辑 |
|------------|--------|----------------|
| "分析一下这个竞品"/"帮我看看这个产品" | 竞品分析 | 需要提取竞品信息，找到差异化机会 |
| "这个产品有什么问题"/"它做得好不好" | 竞品分析 + 需求发现 | 先分析竞品，再找到我们的机会 |
| "我们和XX有什么区别" | 竞品分析 | 对标分析，找到差异化定位 |
```

### 4.2 模块依赖关系

```
竞品分析 可以单独使用：
- 用户只提供竞品链接 → 输出竞品分析报告

竞品分析 也可以作为 ②机会评估 的输入：
- 竞品分析 → 发现差异化机会 → 进入机会评估
- 竞品分析 → 发现竞争过于激烈 → Kill 建议

竞品分析 还是 ③PRD撰写 的补充输入：
- PRD 中新增 §0.5 竞品对标章节
- 差异化功能优先级更高
```

## 五、技术实现

### 5.1 工具集成

| 工具 | 用途 | 触发条件 |
|------|------|---------|
| axure-online MCP | 提取公开 Axure 原型 | 用户提供 `*.axshare.com` 链接 |
| axure-local MCP | 提取本地 Axure 文件 | 用户提供本地文件路径 |
| web_fetch | 抓取产品网页内容 | 用户提供产品链接 |
| multi-search-engine | 搜索竞品信息 | 用户提到竞品名称 |

### 5.2 工作流自动化

```python
# 竞品分析自动化流程
def competitive_analysis(input_type, input_value):
    # 1. 根据输入类型选择工具
    if input_type == "axure_online":
        data = axure_online_mcp.fetch(input_value)
    elif input_type == "axure_local":
        data = axure_local_mcp.scan(input_value)
    elif input_type == "web":
        data = web_fetch(input_value)
    else:
        data = {"text": input_value}
    
    # 2. 提取结构化信息
    product_info = extract_product_info(data)
    
    # 3. 分析功能模块
    features = analyze_features(product_info)
    
    # 4. 对比用户画像
    user_comparison = compare_users(product_info)
    
    # 5. 识别差异化机会
    opportunities = find_differentiation(features, user_comparison)
    
    # 6. 生成分析报告
    report = generate_report(product_info, features, user_comparison, opportunities)
    
    return report
```

- 产品名称：AI 智能体创作平台

#### 【目标用户】
- 主要用户：艺术爱好者、创作者
- 次要用户：普通用户（体验创作乐趣）

#### 【核心功能模块】

- 我们的机会：垂直领域的深度智能体、B2B 市场的定制化服务
- 差异化定位：专注设计领域的 AI 智能体平台
