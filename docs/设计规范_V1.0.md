# 陪伴机器人首页改版 — Figma 设计规范

## 一、设计概览

### 1.1 设计理念
**「暖客厅风」** — 温暖、友好、清晰、不幼稚  
面向老年用户，传递安全感和亲切感，同时保持现代感。

### 1.2 核心改动点
| 模块 | 改动内容 |
|------|---------|
| 快捷入口 | ✅ 增加文字标签（相册/视频/通话/留言/导航） |
| 滑动引导 | ✅ 增加右箭头指示器 + 页面指示器 + 优化文案 |
| 天气模块 | ✅ 增加穿衣/出行建议卡片 |
| 照片区域 | ✅ 增加「查看全部」按钮 |
| 视觉适配 | ✅ 大字号 + 高对比度 + 圆润图形 |

## 三、字体规范

### 3.1 字号体系（适配老年用户）
| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| H1 | 36px | 700 | 1.3 | 页面标题 |
| H2 | 32px | 700 | 1.4 | 区块标题 |
| H3 | 28px | 600 | 1.5 | 卡片标题 |
| Body Large | 26px | 400 | 1.6 | 重要正文 |
| Body | 24px | 400 | 1.6 | 常规正文 |
| Caption | 20px | 400 | 1.5 | 辅助说明 |

### 3.2 字体家族
```
主字体：PingFang SC / Microsoft YaHei
备选：-apple-system, sans-serif
```

## 五、组件规范

### 5.1 顶部状态栏
```
高度：104px
背景：#FFFFFF
底部边框：2px solid #E8E0D8
内边距：24px 48px
Logo尺寸：56x56px（圆角16px）
状态字号：28px
```

### 5.2 日历面板
```
宽度：360px
背景：#FFFFFF
圆角：24px
内边距：32px
日期字号：24px
今日高亮：#FF8C42 背景 + 白色文字
事件标记：底部 8px 圆点（#4A90D9）
```

### 5.3 天气卡片
```
背景：渐变 #4A90D9 → #6BB3F0（135deg）
圆角：24px
内边距：32px 48px
温度字号：64px（font-weight: 300）
建议字号：26px
点击展开详情
```

### 5.4 照片网格
```
布局：4列，间距 20px
单个比例：4:3
圆角：16px
悬停：scale(1.03) + 阴影
「查看全部」按钮：26px 橙色文字 + 背景 rgba(255,140,66,0.1)
```

### 5.5 快捷入口
```
图标容器：88x88px，圆角 24px
图标字号：44px
标签字号：28px，字重 600
触控热区：不小于 120px
悬停：上移 8px + 背景色变化
```

**配色方案：**
| 入口 | 渐变色 |
|------|--------|
| 相册 | `#FF8C42 → #FFB885` |
| 视频 | `#4A90D9 → #6BB3F0` |
| 通话 | `#5BC67A → #7DD99A` |
| 留言 | `#F5A623 → #FFCA5F` |
| 导航 | `#9B6FD9 → #C49EF2` |

### 5.6 底部导航
```
高度：80px
背景：#FFFFFF
顶部边框：2px solid #E8E0D8
提示文字：26px #9A9A9A
箭头动画：bounce-right 1s infinite
页面指示器：14px 圆点，活跃态放大 1.3x
```

## 六、动效规范

### 6.1 过渡动画
| 场景 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 卡片悬停 | translateY(-4px) | 0.3s | ease |
| 照片悬停 | scale(1.03) | 0.3s | ease |
| 按钮悬停 | 背景色变化 | 0.3s | ease |
| 箭头指示 | translateX(8px) | 1s | infinite |

### 6.2 微交互
- 点击卡片：涟漪效果
- 切换照片：淡入淡出
- 展开天气：向下滑出

---

## 七、无障碍规范

### 7.1 对比度
- 所有正文文字与背景对比度 ≥ 4.5:1
- 大标题对比度 ≥ 3:1

### 7.2 触控尺寸
- 最小点击区域：48x48px
- 推荐快捷入口触控区：120x120px

### 7.3 语音支持
- 所有图标配文字标签
- 支持语音播报当前页面内容
