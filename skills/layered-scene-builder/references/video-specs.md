# 视频规格参考

本文件包含：视频风格推荐、视频时长推荐、libtv风格关键词模板。

---

## 一、视频风格推荐

**核心原则：画面祥和，里层锋利。风格选择影响叙事的承载力和可信度。**

---

### 推荐风格（按优先级排序）

#### 首选：水墨国风

| 维度 | 说明 |
|------|------|
| **特点** | 淡淡留白、意境深远、构图古典、色彩素雅 |
| **适合主题** | 感情纠葛、千古文人、历史典故、讽刺批判 |
| **叙事优势** | 留白本身就是语言——空白处懂的人自己脑补 |
| **AI生成质量** | 最稳定，模型训练数据最丰富 |
| **Prompt关键词** | 中国水墨风格，淡淡留白，古典构图，意境深远，笔墨感 |

**生成示例 Prompt 片段：**
> 水墨国风，淡淡留白，古典庭院，杏花如雪，蝴蝶翩跹，书生独坐，意境深远

---

#### 备选A：工笔淡彩

| 维度 | 说明 |
|------|------|
| **特点** | 线条细腻、色彩温润、细节丰富 |
| **适合主题** | 需要更多视觉暗号/暗号藏在细节里 |
| **叙事优势** | 工笔的线条感可以画更多"暗号"，适合暗号流 |
| **AI生成质量** | 中等，对模型要求高，容易崩 |
| **Prompt关键词** | 中国工笔淡彩，细腻线条，古典细节，温润色彩，手绘质感 |

**生成示例 Prompt 片段：**
> 工笔淡彩中国画，细腻线条，庭院深处，杏花掩映，书生提笔，画面精致

---

#### 备选B：古风水墨插画

| 维度 | 说明 |
|------|------|
| **特点** | 比纯水墨多一点色彩，比工笔多一点写意，介于两者之间 |
| **适合主题** | 不想太素净、想要画面更有层次感 |
| **叙事优势** | 色彩渐变可以做隐喻（繁华→凋零） |
| **AI生成质量** | 较稳定 |
| **Prompt关键词** | 古风水墨插画，淡雅设色，古典意境，诗意画面 |

---

### 不推荐风格

| 风格 | 原因 |
|------|------|
| 赛博朋克/科幻未来 | 跟隐晦叙事的调性完全不搭，画面语言冲突 |
| 抽象表现主义 | 隐喻无法落地，太模糊，受众get不到 |
| 浓烈暗黑/血腥暴力 | 违背"画面祥和"的前提，直接触发审查 |
| 日系二次元/厚涂插画 | 非中式审美会破坏意境感，除非内容本身是现代题材 |
| 写实摄影风格 | AI生成写实视频容易崩，且隐喻空间受限 |

---

### 风格选择指南

| 内容类型 | 推荐风格 |
|---------|---------|
| 古代才子佳人/文人故事 | 水墨国风 |
| 历史人物/官员/商贾 | 工笔淡彩（细节多） |
| 现代都市/情感故事 | 古风水墨插画（调性统一） |
| 讽刺社会现象/群像 | 茶馆/市集场景 + 水墨国风 |
| 感慨命运/时代变迁 | 湖畔/山路 + 水墨留白 |

## 二、视频时长推荐

**核心原则：隐喻需要时间沉淀，但不能长到稀释张力。**

---

### 单镜头推荐时长

| 时长 | 适用场景 | 理由 |
|------|---------|------|
| **15秒** | 标准叙事场景 ⭐**默认** | 短平快，隐喻点到即止，AI生成质量最稳 |
| **10秒** | 极短/快节奏 | 单一意象，适合系列片中的单个镜头 |
| **20秒** | 稍长/意象稍多 | 适合需要多一个层次的场景 |
| **30秒** | 复杂场景（多个意象叠加） | 需要交代更多视觉暗号，适合进阶版隐喻 |

---

### 系列短片推荐结构

建议用**多镜头组合**讲述一个完整隐喻：

```
场景1（15秒）：建立表面祥和
    ↓
场景2（15秒）：出现关键意象（隐喻种子）
    ↓
场景3（15秒）：意象展开/主角反应（懂的人开始联想）
    ↓
场景4（15秒）：收尾/意象消失/画面定格
```

**总时长：约1分钟**，适合短视频平台（抖音/B站/视频号）

---

### 时长禁区

| 类型 | 问题 |
|------|------|
| **超过60秒的单镜头** | AI生成质量下降，隐喻被稀释 |
| **少于8秒** | 隐喻来不及展开，观众只能看到表层 |
| **画面一直不变** | 即使是短片，也要有一两个视觉变化点 |

---

### 时长与隐晦度的关系

| 隐晦度 | 推荐时长 | 适合节奏 |
|--------|---------|---------|
| 高（几乎不说破） | 20-30秒 | 让受众慢慢发现 |
| 中（有线索可猜） | 15-20秒 | 适当加速，给提示 |
| 低（稍微明显） | 10-15秒 | 快节奏，点到即止 |

## 三、libtv Prompt 风格模板

> **说明：** 以下模板仅供参考，实际使用时根据具体AI视频工具调整关键词顺序和权重。

### 水墨国风标准模板

```
中国水墨风格，淡淡留白，古典构图，意境深远，
[场景描述]，[主要意象A]，[主要意象B]，
[动态描写]，禅意氛围，老少皆宜，无暴力
```

**示例：**
```
中国水墨风格，淡淡留白，古典构图，意境深远，
庭院深处，杏花如雪飘落，书生独坐石桌旁，
蝴蝶绕花盘旋，书生低头执笔，墨迹未干，
微风轻拂，花瓣缓缓落地，禅意氛围，老少皆宜，无暴力
```


## 四、快速选择清单

拿到一个内容后，按这个顺序做决定：

```
① 主题类型？
   └─ 古风/文人 → 水墨国风
   └─ 历史/细节 → 工笔淡彩
   └─ 现代/情感 → 古风水墨插画

② 隐晦程度？
   └─ 高隐晦 → 20-30秒单镜头
   └─ 中隐晦 → 15-20秒
   └─ 低隐晦 → 10-15秒

③ 叙事规模？
   └─ 单镜头 → 10-30秒
   └─ 短片（多镜头）→ 4个镜头 × 15秒 ≈ 1分钟
```
