## 案例一：元稹型（深情表演 + 实际薄情）

**用户输入：**
> 元稹，写出"曾经沧海难为水，除却巫山不是云"，表面是千古第一痴情人，实际上对初恋崔莺莺始乱终弃，对亡妻韦丛写下深情悼诗转头就找薛涛，频繁换伴、功利倾向明显。

**第一步：三层面拆解**

| 层面 | 分析结果 |
|------|---------|
| 表层形象 | 痴情才子，悼念亡妻，千古深情 |
| 深层真相 | 写完悼诗第二天就去见薛涛，对每位女子都写过深情文字，转身便忘 |
| 作者观点 | 讽刺：深情是表演，薄情是本色；文字越美，人越虚伪 |

**第二步：场景选择**

选"庭院独坐 + 茶馆议论"组合：
- 庭院：展示他独处时的"深情表演"
- 茶馆：展示外界对他的议论和暗示

**第三步：输出视频脚本**

---

**【视频脚本：庭院深处】**

**【画面描述】**
春日黄昏，庭院杏花如雪，飘落满阶。书生独坐书房，案上摊开一卷新写的诗稿，笔迹工整，落款处写着亡妻的名字。窗外有只蝴蝶飞入，绕着烛火盘旋，书生抬头望了一眼，目光幽深，又低头继续抄写。案旁放着另一封信笺，已封好尚未寄出，封口处露出一角粉红信纸。庭中燕雀啁啾，岁月静好，书生执笔如旧，仿佛这世间再无旁的牵挂。

**【表层叙事】**
一位才子在亡妻故去后独守书房，以诗寄情，庭院静谧，时光仿佛凝固。

**【里层叙事】**
他一边为亡妻写悼诗，一边封好给另一位女子的信。杏花飘落是世间最美的戏台，而他是最敬业的演员。

**【隐喻对照】**
- 杏花落满阶 → 表层：春日美景 / 里层：处处留情的暗语
- 蝴蝶绕烛火 → 表层：轻盈美丽 / 里层：旧情未断，新欢又来
- 粉红信笺角 → 表层：未寄出的家书 / 里层：另一段感情的痕迹
- 燕雀啁啾 → 表层：祥和安宁 / 里层：热闹是假的

傍晚茶馆，灯火初上。说书人拍案讲起一位痴情才子的故事：他在亡妻过世后写下千古名篇，此生不再娶。座中一位老者端着茶，听着听着忽然笑了，低声说了一句："他那诗写完的墨迹还没干，城西井边的故事就又热闹起来了。"旁人没听清，说书人却顿了一下，茶馆里笑语依旧，只有那盏茶凉得比平时快了些。

## 案例二：表里不一型（表面君子 / 实际伪善）

**用户输入：**
> 某人表面是大善人、慈善家，实际克扣善款、摆拍作秀、对外形象与私下行为截然相反。

**第一步：三层面拆解**

| 层面 | 分析结果 |
|------|---------|
| 表层形象 | 慈善家，大善人，满口仁义道德 |
| 深层真相 | 摆拍消费苦难，克扣善款，对外形象是精心维护的面具 |
| 作者观点 | 揭露：伪善比恶更可恶，用善为恶是最大的恶 |

**第二步：场景选择**

选"老宅访旧 + 茶馆议论"：
- 老宅：展示他精心维护的形象下的真相
- 茶馆：展示外界逐渐觉醒的认知

**第三步：输出视频脚本**

---

**【视频脚本：善堂旧事】**

**【画面描述】**
阳光透过雕花窗棂，照进一间老宅正堂。墙上挂着"仁者爱人"的匾额，落款是某位商号的名字。匾下立着一排木柜，柜门紧锁，锁上积了灰。柜旁有一张八仙桌，桌上摆着几本账簿，纸页泛黄，边角卷起。院中有孩童追逐嬉闹，笑声清脆。一只狸猫蹲在门槛上，懒洋洋地眯着眼，像是见惯了来去的人。堂中有一口铜钟，钟声已许久未响，钟面上有一道裂纹。

**【表层叙事】**
一间老宅，挂满荣誉，岁月沉淀着慈善的过往。

**【里层叙事】**
匾额在墙上，锁已落灰，账簿无人翻阅，钟已裂开——所有的"大善"都只留在匾额上。

**【隐喻对照】**
- "仁者爱人"匾 → 表层：道德标杆 / 里层：空洞的口号
- 积灰的柜锁 → 表层：妥善保管 / 里层：早已无人问津
- 泛黄账簿 → 表层：记录详实 / 里层：无人核查
- 铜钟裂纹 → 表层：年代久远 / 里层：信仰已破
- 狸猫眯眼 → 表层：岁月静好 / 里层：见惯了一切，懒得说破

**【敏感词检查】** ✅ 通过 —— 无直接指控，画面日常

## 案例三：循环命运型（历史不断重演）

**用户输入：**
> 某段历史/某种现象，不断重复，每一代人都以为自己不同，最后殊途同归。

**三层面拆解**

| 层面 | 分析结果 |
|------|---------|
| 表层形象 | 每代人都觉得自己是觉醒者、破局者 |
| 深层真相 | 换了一套说辞，内核完全一样 |
| 作者观点 | 感慨/无奈：历史的循环无人能逃 |

**【视频脚本：渡口又渡口】**

**【画面描述】**
清晨江边，第一艘渡船靠岸。书生模样的人下船，身后妻子为他整理行囊，叮嘱再三。船家摇橹，水波不兴。镜头缓缓拉开，第二艘渡船靠岸，同样书生模样的人下船，身后同样有妻子整理行囊、叮嘱再三。又一艘，又一人，如此往复，岸边石阶长满青苔，每一级都磨得发亮，似乎诉说着无尽的重复。远山如黛，江水东流。

**【表层叙事】**
渡口送别，是古往今来最寻常不过的场景。

**【里层叙事】**
每一艘船上下来的都是同一个人——换了一身衣服，一段历史，却走着同一条路。

**【隐喻对照】**
- 渡船循环靠岸 → 表层：人来人往 / 里层：历史在重复
- 石阶青苔 → 表层：岁月痕迹 / 里层：每一代人都踩在同一处
- 远山如黛 → 表层：风景依旧 / 里层：环境未变，人性未变
- 江水东流 → 表层：自然规律 / 里层：不可逆转的时间与命运

**【敏感词检查】** ✅ 通过 —— 无敏感内容
