# 场景模板参考

以下场景模板可直接调用或组合使用。选好场景后，替换其中的可变元素即可。

---

## 模板一：庭院独坐

**场景设定：** 主角独自在院中，周围环境祥和，但内心或行为暗藏玄机。

**标准结构：**
- 开局：季节 + 环境（花/树/光影）
- 中段：主角动作（写字/喝茶/发呆）
- 穿插：某个意象出现（蝴蝶/孤雁/落花）
- 收尾：另一个意象呼应开头

**可变元素：**
| 位置 | 选项 |
|------|------|
| 季节 | 春日/夏夜/秋晨/冬雪 |
| 植物 | 杏花/桂花/梅花/芭蕉 |
| 意象A | 蝴蝶（表层：美丽/里层：留情） |
| 意象B | 孤雁（表层：自由/里层：被弃） |
| 动作 | 写字/棋局/抚琴/整理旧物 |

**示例框架：**
> 春日午后，庭院杏花如雪。主角独坐石桌旁，手中执笔，似在写信。案上墨迹未干，窗外有蝶飞来，绕着花瓣盘旋。主角抬头看了一眼蝴蝶，目光复又落回信纸，继续写完最后一行。落笔时，袖中滑出一枚旧书签，悄然落地，他似乎没有察觉。

## 模板二：渡口送别

**场景设定：** 两人在渡口告别，表面是普通离别，实际暗藏后续故事。

**标准结构：**
- 环境：渡船/水波/远山
- 送别：主角与另一人互动
- 穿插：一个信物/意象出现又消失
- 暗示：另一人在远处等待或已离开

**可变元素：**
| 位置 | 选项 |
|------|------|
| 送别者 | 新婚妻子/旧友/父亲 |
| 信物 | 扇坠/玉佩/书信/花钗 |
| 意象 | 孤雁（表层：单飞/里层：另觅） |
| 环境 | 夕阳/晨雾/雨后 |

**示例框架：**
> 渡船缓缓靠岸，书生整理行囊。身后妻子为他系好披风，目光温柔。远处有只孤雁掠过水面，书生抬头看了一眼——那是他上一段感情的信物，此刻被他悄然收入袖中。船头老人摇橹，水波不兴，书生回头对妻子微微一笑，转身登船。

## 模板三：茶馆闲话

**场景设定：** 茶馆中有人说书/闲聊，表面是市井烟火，实际暗讽某人某事。

**标准结构：**
- 环境：茶馆热闹/说书人/评弹声
- 议论：旁白或角色提及某人某事（表面赞美）
- 穿插：一个小细节暴露真相（与表面矛盾）
- 收尾：众人附和，主角沉默

**可变元素：**
| 位置 | 选项 |
|------|------|
| 议论对象 | 某位才子/某位官员/某位商人 |
| 表面评价 | 痴情/忠诚/仁义/勤俭 |
| 破绽细节 | 漏嘴/前后不一/行为矛盾 |
| 旁观者 | 老人（见多识广，意味深长）/孩童（天真直言） |

**示例框架：**
> 茶馆里，说书人正讲着一位痴情才子的故事，说他如何为亡妻守节、如何写下千古名篇。座中一位老人听着，缓缓端起茶盏，插了一句："他那首诗写完的第二天，城西的薛涛井边可热闹得很呐。"众人哄笑，说书人脸色微变，茶馆里依旧热闹如旧。

## 模板四：老宅访旧

**场景设定：** 主角回到某个旧地/老宅，表面是怀旧，实际在重访某段被隐藏的历史。

**标准结构：**
- 环境：老宅/旧居，陈设依旧
- 发现：主角发现某个旧物（信/物/照片）
- 对比：旧物内容与现状形成反差
- 结尾：主角将旧物放回/带走/销毁

**可变元素：**
| 位置 | 选项 |
|------|------|
| 旧物 | 书信/画像/花钗/诗稿 |
| 对比 | 当年的承诺 vs 今日的选择 |
| 场景 | 阁楼/书房/后院枯井/祠堂 |
| 氛围 | 沉重/释然/无奈/沉默 |

**示例框架：**
> 老宅后院，荒草没膝。主角推开落灰的书房，抽出一本旧册，里面夹着一封泛黄的信笺。信上说："此生唯你。"落款是写诗的那一年。主角翻到册子最后一页，那里还夹着另几张字条，是后来另几位女子的名字。主角沉默片刻，将信笺放回原处，轻轻合上书房的门。

## 模板五：湖畔扁舟

**场景设定：** 船上两人，表面是悠闲泛舟，实际暗藏某种权力/情感关系。

**标准结构：**
- 环境：湖面/扁舟/远山
- 人物：两人同舟，关系微妙
- 意象：水中倒影/鱼/莲/孤岛
- 暗示：一人说一句话，表面客气，实际有弦外之音

**可变元素：**
| 位置 | 选项 |
|------|------|
| 人物关系 | 主仆/师生/旧友/夫妻 |
| 弦外之音 | 试探/警告/讽刺/妥协 |
| 意象 | 莲（表层：和谐/里层：淤泥） |
| 环境 | 晨雾/晚霞/月夜 |

## 场景选择指南

| 内容类型 | 推荐场景 |
|---------|---------|
| 感情纠葛/始乱终弃 | 渡口送别、湖畔扁舟 |
| 表里不一/伪君子 | 茶馆闲话、庭院独坐 |
| 被遗忘/被掩盖的真相 | 老宅访旧、书房翻书 |
| 循环重复/历史重演 | 山路、古道、驿站 |
| 繁华背后的荒凉 | 市集（收摊后）、宴会（散场后） |

---

## 意象搭配原则

1. **同调原则**：意象表层和里层的情绪方向一致
   - 好例子：杏花（表层：春日喜悦）+ 落花（里层：美好易逝）= 表面欢快，内里感伤
   - 好例子：灯笼（表层：温暖）+ 风吹歪（里层：不稳）= 表面温馨，内里危机

2. **反差原则**：意象表层和里层方向相反，制造张力
   - 好例子：墨迹（表层：深情记录）+ 起身离去（里层：言不由衷）
   - 好例子：新婚披风（表层：恩爱）+ 袖中旧物（里层：旧情难忘）

3. **禁忌**：不要用一个意象同时说两件完全不相关的事，表里必须有逻辑关联
