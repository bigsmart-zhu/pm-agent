# Layered Scene Builder — 深度叙事场景构建器

## 核心原则

**表面祥和，里层锋利。** 画面是岁月静好，细节处处藏刀。

输入一个真实的人/事/现象 → 输出一个表里不一的故事场景。
懂的人一看就懂，不懂的人只看到岁月静好。

---

## 工作流

```
用户输入文字
    ↓
【第一步】三层面拆解
    ├─ 表层形象：表面看起来是什么样的（人设/形象/外壳）
    ├─ 深层真相：实际是怎样的（反转/矛盾/破绽）
    └─ 作者观点：想表达什么情感（讽刺/批判/感慨/无奈）
    ↓
【第二步】场景设计
    ├─ 选一个祥和场景（庭院/茶馆/市集/渡口/书房/山路……）
    ├─ 设计视觉元素，每个元素做隐喻映射
    └─ 表层叙事 + 里层叙事 双轨并行
    ↓
【第三步】输出视频脚本
    ├─ 画面描述（祥和、老少皆宜）
    ├─ 隐藏线索标注（懂的人能看懂）
    └─ 隐喻对照表（可选）
```

---

## 第一步：三层面拆解模板

对输入内容，逐一回答：

| 层面 | 问自己 | 输出 |
|------|--------|------|
| **表层形象** | 他/她/它对外展示什么？旁人怎么评价？ | 一句话描述 |
| **深层真相** | 实际呢？有哪些矛盾或破绽？ | 列出2-3条 |
| **作者观点** | 写这段文字的人想表达什么态度？ | 讽刺/揭露/感慨/无奈/批判 |

> **记忆口诀：外壳是什么，壳里装什么，写的人站哪边。**

---

## 第二步：场景元素库

选择场景时，优先从以下元素库中选取，再做隐喻映射：

### 场景类型（祥和基底）

| 场景 | 表层氛围 | 常配意象 |
|------|---------|---------|
| 庭院 | 宁静悠然 | 花落、棋盘、茶盏、燕归 |
| 茶馆 | 烟火人间 | 说书人、评弹、窗外雨 |
| 渡口 | 离别/漂泊 | 船橹、水波、孤雁、夕阳 |
| 书房 | 雅致沉静 | 笔墨、孤灯、雁过、书签 |
| 市集 | 热闹祥和 | 货郎、孩童、灯笼、炊烟 |
| 山路 | 超然出世 | 雾气、古松、落叶、樵歌 |
| 湖畔 | 空灵悠远 | 扁舟、芦苇、晚霞、鸬鹚 |
| 老宅 | 怀旧厚重 | 匾额、族谱、桂花、门槛 |

### 意象隐喻库（可复用）

| 意象 | 表层含义 | 里层映射 |
|------|---------|---------|
| 蝴蝶 | 轻盈美丽 | 处处留情/旧情难忘 |
| 孤雁 | 离群单飞 | 被弃/另寻新欢 |
| 落花 | 伤春美好 | 美好易逝/被践踏 |
| 杏花 | 春日喜讯 | 表面忠贞/实则飘零 |
| 燕子 | 归来守时 | 始乱终弃/重蹈覆辙 |
| 茶凉 | 自然现象 | 热情消退/关系变淡 |
| 墨迹 | 留字传情 | 深情表演/言不由衷 |
| 伞 | 遮风挡雨 | 保护者/加害者同体 |
| 镜子 | 映照真实 | 表里不一/自我审视 |
| 灯火 | 温暖指引 | 希望/虚假的希望 |

## 第三步：输出格式

标准视频脚本格式如下，直接可用于AI视频生成：

```
【视频脚本】

【画面描述】
（祥和、老少皆宜的具体场景描写，150-250字，视觉元素丰富）

【表层叙事】
（这段描写看起来在讲什么，一句话）

【里层叙事】
（实际暗藏什么，一句话）

【隐喻对照】
- 意象A → 表层/里层
- 意象B → 表层/里层
- ...

【敏感词检查】
（确认表面文字不触发审查，同时里层意义清晰）
```

## 第四步：调整参数

根据用户需求，可调整：

| 参数 | 选项 | 说明 |
|------|------|------|
| **隐晦度** | 高/中/低 | 高=几乎不说破，中=有线索可猜，低=稍微明显 |
| **画面风格** | 古风/现代/民国/架空 | 影响场景和意象选择 |
| **情感基调** | 温和讽刺/强烈批判/感伤感慨/冷峻揭露 | 影响措辞和意象搭配 |
| **篇幅** | 短（15秒）/中（30秒）/长（1分钟） | 影响场景元素数量 |

> **视频风格参考（详见 `references/video-specs.md`）：**
> - **首选：水墨国风** — 淡淡留白，意境深远，AI生成最稳定
> - 备选：工笔淡彩（细节多）/ 古风水墨插画（有色彩）
> - 排除：赛博朋克、抽象表现、暗黑暴力（违背后层祥和原则）
>
> **视频时长参考（详见 `references/video-specs.md`）：**
> - 标准推荐：**15秒/镜头**
> - 单镜头范围：10秒～30秒
> - 系列短片：4镜头×15秒≈1分钟，适合抖音/B站/视频号

---

## 禁忌事项

- **不直接说破**：不用"他其实是个渣男"这种直白句式，所有批判藏在意象里
- **画面必须祥和**：禁止暴力、血腥、恐怖、过于阴暗的视觉描写
- **表里必须统一**：每个意象的表层含义和里层含义必须共存于同一画面，不能割裂
- **避免审查敏感**：政治/宗教/色情相关直接规避，换意象或换场景

## 快速参考（常用）

### 视频风格选择

| 内容类型 | 推荐风格 |
|---------|---------|
| 古代才子佳人/文人故事 | 水墨国风 ⭐首选 |
| 历史人物/官员/商贾 | 工笔淡彩 |
| 现代都市/情感故事 | 古风水墨插画 |

**Prompt关键词模板：**
> 中国水墨风格，淡淡留白，古典构图，意境深远，[场景]，[意象A]，[意象B]，[动态]，禅意氛围，老少皆宜

### 视频时长选择

| 时长 | 适用 |
|------|------|
| **15秒** | **标准推荐** ⭐ |
| 10秒 | 极短/快节奏 |
| 20秒 | 稍长/意象稍多 |
| 30秒 | 复杂场景 |

系列短片：4个镜头 × 15秒 ≈ 1分钟（适合抖音/B站/视频号）
